Licenses for ScreenshotApp

ScreenshotApp's own code is licensed under MIT OR Apache-2.0, at your option
(LICENSE-MIT, LICENSE-APACHE).

The app as distributed is built with PyInstaller and bundles Python and other
people's packages, each under its own license. Two of them, PyQt6 and
PyQt6-Fluent-Widgets, are GPL-3.0 (GPL-3.0.txt), so the built app as a whole is
covered by GPL-3.0. Its complete source is at
https://github.com/JavacrafterDevelopment/ScreenshotApp

Release builds add, in this folder:
  Python-LICENSE.txt          Python's own license
  THIRD-PARTY-LICENSES.txt    every bundled Python package with its license text
